# 台股主力訊號監控 · 當沖決策版（v4）

打開網址就能看，**不用安裝任何東西**。可放上 GitHub Pages 免費託管。

> **v4 新增：當沖決策面板** —— 每檔股票最上方直接告訴你「做多 / 做空 / 觀望」，並算出進場區間、停損、目標 1、目標 2 與 R:R。

## 這個版本有什麼

- **⚡ 當沖決策面板（最上方，v4 新增）**：大字方向（做多紅／做空綠／觀望灰）＋信心度＋一句話理由，下方四個價位表。
- **即時報價**：股票代號/名稱、成交價、漲跌與漲跌幅、開高低、成交量、更新時間，紅漲綠跌。
- **主力訊號判讀引擎**：把原版 `rules.py` 的加權判讀邏輯忠實搬過來 —— 綜合分數、分級（強多/偏多/中性/偏空/強空）、信心度、矛盾偵測、警示級訊號。
- **今日主力訊號時間軸**：依時間排序，每則顯示時間／股票／訊號類型／觸發條件數值／訊息內容。
- **自選股**：自己新增/刪除要監控的股票（存在瀏覽器 localStorage，不會上傳）。
- **手機可用**：響應式版面，可「加到主畫面」當 App 用。
- **可調參數**：所有門檻與權重都能在網頁上調整（見下方）。

## 🎯 當沖決策面板的計算邏輯與價位公式

### 一、方向怎麼決定

直接用原版 12 條規則的加權判讀結果（綜合分數 −2 ~ +2）：

| 綜合分數 | 方向 |
|---|---|
| ≥ +1.0 | **做多**（強多） |
| +0.35 ~ +1.0 | **做多**（偏多） |
| −0.35 ~ +0.35 | **觀望**（不給價位） |
| −1.0 ~ −0.35 | **做空**（偏空） |
| ≤ −1.0 | **做空**（強空） |

即使分數達標，以下任一情況仍會降為「觀望」或「暫不建議進場」：
信心度低、多空訊號矛盾、價格在 VWAP 反側（做多但已跌破 VWAP）、距漲跌停不到 1%。

### 二、三個價位怎麼算

先算**波動單位**：

```
ATR = max(今日最高 − 今日最低, 現價 × 0.6%)
```
> 下限 0.6% 是為了避免開盤振幅過小時停損過窄，被雜訊掃出場。

| 項目 | 做多 | 做空 |
|---|---|---|
| **進場區間** | `max(現價 − 0.40×ATR, VWAP − 0.10×ATR)` ~ `現價 + 0.05×ATR`（強多 +0.15） | `現價 − 0.05×ATR`（強空 −0.15） ~ `min(現價 + 0.40×ATR, VWAP + 0.10×ATR)` |
| **停損** | `min(進場下緣 − 0.50×ATR, VWAP − 0.25×ATR)` | `max(進場上緣 + 0.50×ATR, VWAP + 0.25×ATR)` |
| **目標 1** | `進場起算價 + 1.5R` | `進場起算價 − 1.5R` |
| **目標 2** | `進場起算價 + 2.5R` | `進場起算價 − 2.5R` |

其中 **R = |進場起算價 − 停損|**，進場起算價 = 區間較差的那一端（做多用上緣、做空用下緣），寧可保守估。

**為什麼這樣設計**
- **進場不追高**：掛在回測區間，做多的下限鎖在 VWAP 附近 —— 跌破 VWAP 就不該做多。
- **停損有紀律**：先由 ATR 推，再強制落在進場價 **0.4% ~ 1.5%** 之內。太窄會被雜訊掃出場，太寬單筆風險過大。
- **目標看風險報酬**：固定 1:1.5 與 1:2.5，先落袋一半再讓獲利奔跑。

### 三、跳動檔位對齊

所有價位都會對齊台股升降單位，不會出現掛不出去的價格：

| 股價 | 跳動單位 |
|---|---|
| < 10 | 0.01 |
| 10 ~ 50 | 0.05 |
| 50 ~ 100 | 0.1 |
| 100 ~ 500 | 0.5 |
| 500 ~ 1000 | 1 |
| ≥ 1000 | 5 |

> 高價股 tick 可能是 5 點（例如 1250 附近），對齊後停損距離會被推偏，所以程式會**對齊完再逐檔修正**，確保距離仍落在 0.4%~1.5%；目標價則往有利方向取整，確保 R:R 不會因捨入而低於 1.5 / 2.5。

### 四、什麼情況會顯示「暫不建議進場」

- 開盤未滿 15 分鐘（VWAP 未穩定，沿用原版門檻）
- 取樣不足 3 筆
- 成交量低於 20 日均量 15%（流動性不足）
- 漲停／跌停鎖住
- 尚未取得成交價

> 若目前非盤中時段，畫面會標註「目前非盤中時段」，價位仍可計算但下個交易日須重新評估。

### 五、觀望時給什麼

不給假價位，改列「**等什麼條件出現才進場**」：
- 做多條件：站上 VWAP 並維持 N 分鐘、量能放大到 20 日均量 2 倍、帶量突破今日高點
- 做空條件：跌破 VWAP 並維持 N 分鐘、帶量跌破今日低點、五檔轉為委賣壓過委買

畫面上每個面板都有「**ⓘ 計算依據**」可展開，即時顯示這檔股票用了哪些數字、算出什麼。

## 兩種資料模式（自動切換）

| 模式 | 資料源 | 五檔/內外盤 | 說明 |
|---|---|---|---|
| **① 代理模式（完整）** | 自架後端代理 → 證交所 MIS | ✅ 有 | 需先啟動 `proxy.py`（見路線 B） |
| **② 純前端模式（降級）** | 鉅亨網公開報價 | ❌ 無 | 開網址即用，但三條訊號標示不可用 |

> **為什麼純前端拿不到五檔？** 證交所 MIS 端點**沒有回傳 CORS 標頭**，瀏覽器直接呼叫會被擋
> （實測 `TypeError: Failed to fetch`）。鉅亨網雖開放 CORS，但沒有五檔欄位。
> 要完整支援，需自架後端代理（路線 B）或付費資料源。

## 各項主力訊號的判斷條件與可調參數

| 訊號 | 判斷條件 | 可調參數（預設） | 需要代理 |
|---|---|---|---|
| 價格相對 VWAP `tech_vwap` | 價格偏離 VWAP 達門檻且持續 N 分鐘 | `vwapBand` 0.15%、`vwapPersist` 15 分 | 否 |
| 內外盤比 `tech_tape` | 外盤佔比 ≥ 門檻（量增時加分） | `tapeRatio` 0.65 | **是** |
| 大單方向 `tech_big_order` | 單筆增量 ≥ 門檻視為大單，依方向累計淨筆數 | `bigLots` 100 張、`bigValue` 500 萬 | **是** |
| 突破量能 `tech_breakout` | 近 N 分鐘量 / 先前均量 ≥ 門檻，且創當日新高/低 | `breakoutWin` 5 分、`breakoutRatio` 3.0 倍 | 否 |
| 五檔失衡 `tech_book` | 委買/委賣 ≥ 門檻（漲跌停鎖住時不可用） | `bookRatio` 2.0 倍 | **是** |
| 量價關係 `chip_price_volume` | 爆量長紅/長黑/長上影/量縮 | `volSurge` 2.0 倍、`bigMove` 2%、`upperShadow` 0.5、收盤位置 0.7/0.3 | 否 |
| 到價提醒 / 漲跌幅 | 漲跌幅達門檻 | `changeAlert` 5% | 否 |
| 漲跌停 | 觸及漲停/跌停 | — | 否 |

**權重**（原版 `settings.yaml`）：`wVwap`、`wTape`、`wBigOrder`、`wBreakout`、`wBook`、`wPriceVolume`。
**冷卻時間**：`cdBigOrder`、`cdBreakout`、`cdPrice`（避免同類訊號重複轟炸）。

> 以上全部可在網頁右上角「⚙ 參數」調整，設定存在瀏覽器本機。

## 如何放到 GitHub 並開啟 GitHub Pages（5 步，全部在網頁上點選）

1. 登入 GitHub，點右上角 **+** → **New repository**，名稱隨意（例如 `twstock-web`），選 **Public**，按 **Create repository**。
2. 在新 repo 頁面點 **uploading an existing file**，把 `index.html` 與 `README.md` 拖進去，按 **Commit changes**。
3. 點 repo 上方的 **Settings** → 左側 **Pages**。
4. **Source** 選 `Deploy from a branch`，**Branch** 選 `main` 與 `/ (root)`，按 **Save**。
5. 等 1 分鐘，重新整理 Pages 頁面，最上方會出現你的網址（形如 `https://你的帳號.github.io/twstock-web/`）。

> 全程不需要安裝任何軟體，也不需要打任何指令。

## 怎麼用

打開網址 → 輸入股票代號（例如 `2330`）按「加入監控」→ **看每張卡片最上方的當沖決策面板**（做多/做空 + 三個價位）→ 再看下方的今日主力訊號時間軸，就知道當天主力在幹嘛。

**當沖面板怎麼讀**
1. 先看大字方向與信心度 —— 信心度「低」就不要進場。
2. 進場區間：掛單用，不要用市價追。
3. 停損：**一定要設**，這是唯一的紀律。
4. 目標 1 到了先出一半，目標 2 讓剩下的跑。
5. 若顯示「觀望」，看下方「做多條件 / 做空條件」，等哪一邊先成立再做。
